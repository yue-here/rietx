# The time-of-flight index

Load it when the pattern is a neutron time-of-flight bank: a flight time on `pattern.tof`, a GSAS `.iparm`/`.prm` or a GSAS-II `.instprm` `Type: PNT` calibration beside it. Its heuristics and codes are `references/tof.md`.

*A reference file of the `rietx` skill. The body it belongs to is
[`SKILL.md`](../SKILL.md). Generated by `docs/skill/make_api_index.py` from the
installed package, like [`api.md`](api.md), and loaded only by a session doing
this; everything in `rx.` is `import rietx as rx`.*

## The bank

`rx.read_pattern` puts a declared flight time on `pattern.tof` in µs. The calibration is never in the data file: `rx.read_gsas_tof_iparm` returns one frozen `Instrument` per bank and `rx.read_gsas2_instprm` one from a `Type: PNT` file (both readers are in `api-io.md`), and `rx.Instrument.tof_neutron_bank` builds one by hand. `Refinement.fit` refines one bank like a scan; the result carries `tof`, not `two_theta`, and `result.axis` says which.

- `rx.Instrument.tof_neutron_bank(difc: float, *, two_theta_bank_deg: float, difa: float = 0.0, tzero: float = 0.0, difb: float = 0.0, l1_m: float | None = None, l2_m: float | None = None, capillary_radius_mm: float | None = None, mu_r: float | None = None, profile: ProfileTOF | None = None) -> Instrument` — One detector bank of a neutron time-of-flight diffractometer.
- `rx.TOFSource` — Neutron **time-of-flight** bank: a white beam, a fixed detector angle.
  Fields: `kind: Literal['neutron_tof'] = 'neutron_tof'`, `difc: Parameter`, `difa: Parameter = Parameter(0.0)`, `tzero: Parameter = Parameter(0.0)`, `difb: Parameter = Parameter(0.0)`, `two_theta_bank_deg: float`, `l1_m: float | None = None`, `l2_m: float | None = None`, `profile_tof: ProfileTOF = ProfileTOF(…)`, `incident_spectrum: IncidentSpectrum = IncidentSpectrum(…)`
- `rx.ProfileTOF` — GSAS **type-3** time-of-flight profile coefficients.
  Fields: `alpha0: Parameter = Parameter(0.0)`, `alpha1: Parameter = Parameter(0.0)`, `beta0: Parameter = Parameter(0.0)`, `beta1: Parameter = Parameter(0.0)`, `sig0: Parameter = Parameter(0.0, min=0.0)`, `sig1: Parameter = Parameter(0.0, min=0.0)`, `sig2: Parameter = Parameter(0.0, min=0.0)`, `gam0: Parameter = Parameter(0.0)`, `gam1: Parameter = Parameter(0.0)`, `gam2: Parameter = Parameter(0.0)`
- `rx.IncidentSpectrum` — The moderator spectrum a time-of-flight bank still carries, or none.
  Fields: `itype: int = 0`, `coefficients: list[Parameter] = []`, `tof_min_us: float | None = None`, `tof_max_us: float | None = None`
