# The hand-kept half of the term list: words a crystallographer reads in this
# manual that the en_GB dictionary lacks.  `docs/vale/terms.py` merges it with
# the names `rietx.help` declares and writes Vale's accept list from both.
#
# One term per line, spelled as a reader should see it.  A word written in
# lower case may open a sentence; one with a capital keeps it everywhere, so
# Vale flags "Topas" and "rietveld".  A synonym this manual does not use
# belongs on the reject side, `docs/vale/rietx/Terms.yml`, never here.
#
# Chosen 2026-10-16 from the words Vale flagged over the old manual, the new
# tree and the generated Reference bodies.  Left out on purpose: American
# spellings (polarization, serialize), code identifiers (str, bool,
# lor_size), which belong in backticks, and the package's own coinages
# (rankable, replayable).
