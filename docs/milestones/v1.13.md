### A parametric equation takes its subset by condition and its target by glob (1965, closed 2026-11-16)

A parametric equation can now name the patterns it covers by a condition on the coordinate
columns, `where="T < 800"`, and drive a family of parameters with one glob target,
`phases.0.cell.*`. The condition is stored and evaluated again at every resolution, so
dropping a pattern from a library leaves the equation on the same specimens, and a pattern
that joins inside a phase field joins its equation, while the reference and scale stay where
the first resolution froze them. A glob expands into one ordinary declaration per path it can
drive, each with its own coefficients, so a stored result keeps bare targets. Tied, locked and
held matches are skipped; only the floating origin's hold, which the caller did not name,
is reported as `PARAMETRIC_GLOB_SKIPPED`. A condition comparing a
value that is not finite, and a glob matching a rigid body's increment or a moment component,
are refused. The one schema change is the optional `ParametricEquation.where`. Leftovers,
among them a `rietx events` line per equation, are in #1621. PR #1619.
