## How v1.12 is getting here

### 1.11.0 cut and published (closed 2026-11-04)

The fifth weekly cut came eleven days after 1.10.0 and carried 183 merged pull requests.
The staged notes were far from complete. Of the pull requests that changed source and did not
touch the notes, 38 had no mention, and the cut wrote a note for each one a user can see.

Merging #1310 exposed a misreading. The cut had called tutorial 05's Rwp of 0.966 a deliberately
broken series in a stale notebook. It was the 2 % step, and bisection put the change at #1305.
The maintainer ruled that a noise check goes into 1.11 (WP-2086, #1406). The first report, a
series failing at 2 %, was one noise draw. Over 100 draws the reach is a rate, so the notes give
it as one, and they do not claim a plain fit 2 % off is restored.

The cut stayed on kernel wheel 1.3 by the maintainer's merge. `rietx-kernels` 1.4.0 is still
unpublished. Its only caller, `rietx.solve`, is unexported and has a numpy fallback, so no 1.11
user reaches the difference. WP-2043's ground, that nothing calls the 1.4 kernels, no longer holds
as written, and WP-1997 still owes the floor raise. Measured on a real 1.10.0 install, 1.10.0
refuses every structure, history log, refinement result and series result this release writes,
so a `.rex` project saved here does not open there. Tutorial 01's first pass fires
`STAGE_WINDOWS_STALE` with no prose to explain it, and the maintainer left that for later.

The maintainer's merge of #1400 approved the version, the notes and the tag. The nightly on that commit
passed every job, the tag went on it, and the maintainer approved `pypi`. The counts are in the
[v1.11 record's ship appendix](v1.11.md#appendix--acceptance-at-ship-2026-11-04).

### The structural plan frees extinction only where declared (1944, closed 2026-11-05)

`mccusker_structural` freed the Sabine extinction coefficient on every phase, while its
description said "where declared" (issue #877). Over 69 structural-plan fits in the test suite,
1 freed value in 98 passed 3σ, and that one was a false positive on synthetic data. On the QPA
guide's weak CaF₂ phase, the freed coefficient traded against the scale at ρ = +0.998 and moved
the weight fraction from 1.34 ± 0.11 to 3.58 ± 3.53 wt %. The maintainer chose an opt-in on
2026-11-03. `Phase.extinction` now defaults to `None`, a number declares it, and an old file's
stored value opens as a declaration. No surveyed program refines powder extinction unasked
(`docs/practice.md` § Extinction).

A second ruling asked for opt-in physics to stay findable. The first answer, in #1391, was a
residual score test that warned when a phase's strong lines asked for extinction. It fired on
one synthetic family and borrowed the air-scatter screen's threshold. The maintainer reversed it
on 2026-11-04, before it could ship: findable means documented. #1412 removed the warning. The
extinction help entry, the theory page and one skill row now say when and how to declare it.
WP-2087 is to add the same documentation pointers for Stephens strain, anisotropic ADPs, roughness
and absorption. The numbers that moved are staged in the 1.12.0 notes.

### WP-2102: a joint fit takes a PlanSpec (closed 2026-11-05)

A joint fit raised `AttributeError` when handed a `PlanSpec`, the serializable plan that a
project file, a history header and an agent each hold. It now reads every form of plan that a
single fit reads, and a spec and the plan it was built from give bit-identical joint answers.
The cause was a preset name looked up by hand at the call site. `resolve_plan` is the one
authority for that lookup, so the fix routes each site through it.

The same lookup sat in five more places, and each skipped the mode substitution, under which
`"mccusker_default"` in a Le Bail fit is `profile_only`. Both reports and the public
`build_report` now read a plan as the fit that made the result read it. Read by shape,
`build_report` took a preset name as a plan with no stages and vetoed nothing. A project created with a preset name, and the text
document's plan line, now store the preset expanded through the project's mode, as the GUI's
preset route already did. Before, a Le Bail project created with the default name stored and
ran a scale stage the mode force-fixes.

One reading changes. A Le Bail report given `plan="mccusker_default"` now equals the report
under `profile_only`. A scale suggestion that the hand-read preset had vetoed is active again.
That veto was an accident: the report suggests a scale and a Biso on a Le Bail fit, where both
are force-fixed, whatever plan it is given. The finding went to WP-1998.

### The report names axial asymmetry at zero apertures (2054, closed 2026-11-05)

A lab fit that left both axial apertures at 0 had no asymmetry column in Layer 1, so a one-sided
low-angle residual read as a position error and a stiff background (issue #1106, NIST SRM 660c).
The report now compiles a copy of the model with both apertures at
`NOMINAL_AXIAL_APERTURE` = 0.02 and borrows that copy's ∂Ω/∂(S/L) as a fifth column. The column
is projected off the other four in each region, so the four keep the coefficients they had. On
SRM 660c the three regions below 40° read asymmetry first, at 7-9 esd, and
`refine_axial_asymmetry` fires at confidence 0.50. Its rationale says the apertures are 0 and to
take S/L from a standard's calibration or free it in the plan. Freeing both apertures inside the
plan takes Rwp from 0.129 to 0.087. A fit that declares an aperture gets the report it had.

The code shipped in 1.11.0 (#1363). The reporter's request for a noise-only t on each coefficient
is a public report field the fix did not need. It moved to WP-2004, and #1106 stays open for it.

### A stage that crawls stops and says so (1334, closed 2026-11-05)

Issue #222 measured 3.9 % of stages spending 46.6 % of stage time on a median cost gain of 1.23 %.
Those stages ran to their evaluation budget on a cost that was falling too slowly to matter. The
default LM driver now stops a stage once, at the rate of its last 100 evaluations, another 300
would lower χ² by less than χ²_red, the decrease one esd of joint travel buys. By the maintainer's
ruling of 2026-11-03 such a stage reads `converged`, with `termination="slow_descent"`, and the
info code `STAGE_SLOW_DESCENT` names it. Every `StageResult` also carries `rwp` and `termination`,
so a caller can keep the best stage without parsing the event log.

On the suite fixture with #222's shape, the GSAS-II LaB6 recipe, a fit spends 539 evaluations
against 816, and no parameter moves by more than 0.064 esd. Stages that fall fast enough still run
to their budget. `solve_magnetic` on Cr₂WO₆ at 150 K took 3 to more than 10 continuations across
six 1e-14 nudges of one start value on macOS arm64, and now takes at most 1, so a class no longer
drops out of the ranking by rounding there. A bounded first rung the rule stops below the bound counts as complete,
and its chain answers bit for bit as the unbounded one.

The code shipped in 1.11.0 (#1343, #1366). The last test landed in #1430.

### A Le Bail stage repeats its partition until the intensities settle (1542, closed 2026-11-05)

A Le Bail stage used to stop after a fixed three cycles. It now repeats its partition until one
cycle moves less than 1e-7 of the Bragg counts, under a cap of 25 000 cycles (ruling B11 of
2026-10-19). On #740's pattern the fit ends at Rwp 1.07 % against 1.09 % for the true structure,
where three cycles left 1.61 %. Its cell comes within 4.6 ppm of truth, where three cycles left
34.9 ppm. Six other patterns pay up to 2.1× in wall clock. BT-1 LaMnO3 pays 150×, from 0.45 s to
about a minute. A Le Bail cycle is a Richardson-Lucy step, so plain repetition takes thousands of
cycles where peaks overlap, and SQUAREM S3 (Varadhan & Roland 2008) accelerates it.
`lebail_cycles=3, lebail_tol=0.0` is bit-identical to the old loop, and an old history node
replays its fixed three cycles. A partition cut by its cap warns `LEBAIL_CYCLES_AT_CAP`.

The stop reads how fast the intensities move. It does not read how far they have left to go. On FAP a pair
1e-4 Å apart stops at 1e-7 and then swaps over 3000 further cycles, 1.23 σ at that peak and 0.001
esd in the answer. So the tolerance sits at tier 3 with FAP as its stated failing case. The
extinction screen and the Pawley seed keep three fixed cycles. Claude settled three calls under the
maintainer's delegation of 2026-11-05: the tolerance, each line a reader receives, and a final
compile without a re-partition. WP-2062 takes the re-partition question.

The WP's earlier half asked for a finding when a Le Bail background stays at its seed. No statistic
separates a hump from a benign pedestal, so the maintainer ruled on 2026-11-03 for no finding and left
`auto_background`'s `seed` default at `False`. The skill names `rietx.background.snip` and the
failure instead (#1357, #1394, #1434).

### A runaway fit ends without an expensive closing stage (2045, closed 2026-11-06)

A warm fit in a series could walk a parameter far out of range, such as an axial ratio to
557.8, and end its one stage "converged". The closing stage then recompiled at that answer
with every peak window the width of the whole pattern. One evaluation cost about 1 500
times the declared stage's, and the nightly `full` job hit its time limit from 2026-10-23.
The last declared stage now converges at the solver's tolerance whenever a closing stage
follows it (option 5, ruled 2026-10-24). The hostile series in the sequential acceptance
suite finishes in 92 s on an arm64 Mac, and the 2026-11-04 nightly `full` job completed
green in 1:35:41.

The loose tolerance on the other intermediate stages stays the default, on cost grounds the
maintainer ruled on 2026-11-01 and upheld on 2026-11-02. Re-measured behind the closing
stage, it saves 1.06-1.58× in evaluations on FAP, 11-BM NAC and cpd-1a, and moves no answer
by more than 0.0004 plain esd. The code shipped in 1.11.0 (#1161). The audit rows' evidence
was brought up to date in #1317, #1348, #1352 and #1440.

### A site and its own image are one atom on every route (1991, closed 2026-11-06)

A site whose symmetry images coincide is now merged onto its special position on every
route, where before only a CIF read merged it. A stored, hand-edited or code-built
coordinate a hair off a mirror no longer doubles the composition with nothing said.
`SITE_TWINS_MERGED`, `SITE_TWINS_KEPT` and `SITE_DOFS_RENUMBERED` name each merge and each
renumbered direction (#1014, #1223).

The same work found that a path naming an atom by its number did not follow the atom when
two models numbered their atoms differently (#1264). An edit, a series carry and a re-anchor
now follow each atom, and each phase, by name, so a hold, tie or carried value stays on the
atom it was declared on (#1274). A hold on an anisotropic displacement component now follows
its tensor component when a site merges. A series whose `prepare` hook adds or removes a
phase or an atom reports each trajectory for one atom, keyed by its phase's name and its own
label, as the maintainer ruled on 2026-11-01. Duplicate names are refused (#1360). That PR
changed a stored format, and the maintainer approved it by merging it on 2026-11-03. A
`SeriesResult` from 1.10 opens as written, since it never stored the names a conversion
would need. All four PRs shipped in 1.11.0.

### A parametric equation the user writes (1964, closed 2026-11-06)

A joint fit now takes a parametric equation written as text, nonlinear in its coefficients.
`basis="expression"` carries the formula, and `variables=` declares each coefficient as a
`Parameter`. A variable is one shared column however many equations name it, so nine cell
edges can share one Einstein θ. An equation with no target is an intermediate that later
formulas name, such as a calibrated temperature. A variable matched by a
`SharingMap.per_histogram` glob is a column per pattern instead, which is Stinton and Evans's
temperature offset per pattern. The grammar has its own reference page and a Theory section,
and `debye(x)` is a function with its own derivative.

The readers that assumed a linear basis now read a formula too. Each variable returns with
its esd from the joint covariance. `RefinedParametricEquation.evaluate` gives an equation's value and esd
at any coordinate, through its exact gradient. The form test recovers each formula target's own column
through that gradient. Peak-chain columns that a shared variable ties together are taken by
one finite-difference pass per independent direction. `Parameter.expr`, a field that only
ever held `None`, left the schema. A stored null is dropped at read, and a formula there is
refused, naming the equation that replaces it.

Measured: over 12 seeded synthetic ramps a per-pattern temperature offset and the
coefficients it feeds have mean z-scores within 0.13 of zero. The ZrP₂O₇ tutorial's formulas
reproduce the cells TOPAS stores to its printed digits. On WO₃ the formula text matches the
built-in Einstein basis to 3e-8 of an esd, and 11 patterns under WP-1325's protocol bound θ
from above only. The input's own WO₃ protocol waits on the tie WP-2103 gives a joint fit.
