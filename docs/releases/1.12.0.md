### Files that change

`capabilities().schema_version` is `0.61`, where 1.11.0's was `0.60` (WP-1944).
`Phase.extinction` is now optional and defaults to `None`.
Every document 1.11.0 wrote opens here unchanged, and a stored extinction block reads as a declaration.
A phase that declares no extinction stores `null`, and 1.11.0 refuses that value.
So a structure or a `.rex` project saved here does not open in 1.11.0: a project stops at "malformed history record".
A Rietveld result and an instrument saved here open in 1.11.0, measured both ways on the NIST LaB6 fit.
