- **`structure_from_cif` refuses a CIF whose operator loop is a different group from its H-M symbol** (WP-1933, #913).
  A loop that lost the C-centring of `C 1 2/m 1`, or a P6₁ loop under `P 61 2 2`, used to build the loop's smaller group, with half the atoms and no diagnostic.
  It now raises `ValueError` naming both groups, and no keyword overrides it: correct the symbol or the loop. Where the loop lists `x, y, z` alone, it names both remedies: write `P 1` or drop the symbol if the atoms are the whole cell, delete the loop if they are only the asymmetric unit.
  A loop that is another setting or origin of the symbol's group, with the same centring, reads as before, and so does a loop that is no group.
  A closed loop of another type at an origin gemmi does not tabulate (`-x,-y+1/2,-z` under `P 1 21 1`) also used to read, as the symbol, and is refused too.
  A loop of the symbol's type with another number of pure translations a cell is refused as well: `B 1 21 1`, `C -1` or `I -1` whose loop lost its centring is still type 4 or 2, but used to build half the atoms.
  A loop on rhombohedral axes under a bare `R` symbol still reads.
  A loop of `x, y, z` alone under a higher-symmetry symbol is refused too.
  Such a file, often a full-cell export that keeps the symbol for information, used to read as `P 1` with the atoms listed, which was right when the atom list is the full cell.
  Drop the symbol, or write `P 1`, to read it so.

- **A fractional coordinate written `.` or `?` is refused naming the file, the site and the tag** (WP-1933, #913).
  It used to raise pydantic's anonymous "value nan lies outside bounds". An occupancy written `.` or `?` still reads as 1.0.
