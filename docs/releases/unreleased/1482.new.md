- **`read_pattern` reads a GSAS-II project's powder histograms** (WP-1943, #1482).
  A `.gpx` is claimed as the `gsas2_gpx` format, and `scan=` picks one `PWDR` histogram, counted from 0 in file order; `list_scans` names them.
  σ is 1/√w from the histogram's stored weight, a scale checked against the project's own stored Rwp, and a zero weight becomes an excluded region.
  Only constant-wavelength histograms are read; a time-of-flight one is refused by name.
  The pattern's `probe` metadata says whether the histogram is X-ray or neutron, and the GUI's import wizard pre-fills no X-ray instrument for a neutron one.
- **The IUCr CPD round robin on PbSO₄ (Hill 1992) is an acceptance case** (WP-1943, #1482).
  Single-radiation neutron and X-ray fits from the published single-crystal model put every cell edge, coordinate and B of Hill's Table 7 inside the participants' range, and a joint fit finds the neutron wavelength Hill back-calculated.
