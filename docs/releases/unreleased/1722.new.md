- **A fit says when it held an instrument width beside a specimen width of the same shape** (WP-2225, #1722).
  A plan can free U, X or Y beside the specimen width with the same angular shape. Since 1.10 the stage then holds the instrument half of the pair, so the specimen widths are what the plan's stage order left over.
  Such a fit now carries the warning `INSTRUMENT_WIDTH_HELD`. It names the held width terms, the specimen widths beside them and the stage whose values they keep, and suggests calibrating the instrument on a standard first.
  It is a warning under the microstructure and calibration purposes, and moves no number.
  While it fires, `summary(deliverable="microstructure")` prints the size and strain as not quotable.
  Of the eight `rietx compare` standards, it fires on zincite, fluorite, corundum and brucite.
