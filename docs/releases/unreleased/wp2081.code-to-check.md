- **A series no longer raises `SEQUENTIAL_WIDTH_GROWTH`** (WP-2081). It warned when a phase width reached 3× its first measured value while GoF doubled.
  The width's trajectory and each entry's `statistics.gof` are still on the result, so read the two side by side.
  `rietx.sequential.WIDTH_GROWTH_FACTOR`, `WIDTH_GROWTH_GOF_FACTOR` and `WIDTH_GROWTH_SIGMA` are gone, and an import of any of them raises `ImportError`.
  `SeriesResult.summary(deliverable="series")` no longer prints its "widths grown with a worsening fit" row.
  `FitReport.thresholds_version` is `1.15`.
