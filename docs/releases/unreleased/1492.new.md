- **A joint fit takes a structure with soft restraints** (WP-1995, #1492).
  `MultiHistogramRefinement` raised `NotImplementedError` on any `Phase.restraints`; it now fits them.
  A restraint on the shared structure is one row of the joint residual, with no pattern weight, so it does not weigh N times against N patterns.
  A restraint that reads a per-pattern parameter, such as a `ValueRestraint` on `instrument.zero_shift`, is each pattern's own row and carries that pattern's `√w_h`.
  `Stage.restraint_weight_scale` scales both stage by stage, as in a single fit.
  `HistogramResult.restraints` reports each pattern's copy of the structure against every restraint.
  `RESTRAINT_TENSION` on a shared restraint and `RESTRAINT_ON_FIXED_BODY_GEOMETRY` are raised once at the top level; a per-pattern restraint's `RESTRAINT_TENSION` goes on its pattern's list.
