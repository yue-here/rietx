- **`rietx.strategy.magnetic.SOLVE_MINIMUM_RTOL` is gone** (#1424). Two starts are now one minimum when every site's |m| agrees within `SOLVE_MINIMUM_MODULUS_SIGMA` (3) combined esds, so code that reads or patches the old constant raises `AttributeError`. The caveat that reported them now reads `class N: … starts stopped at … places …`; code that matched `distinct minima` or `multimodal` in `MagneticSolution.caveats` finds nothing.
