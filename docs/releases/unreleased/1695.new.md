- **`rietx runs` summarises a batch's runs** (WP-1464, #1695).
  `rietx runs [dir] [--label NAME] [--json]` reads the recorded runs under a directory, one block per `label=`.
  Each block counts the runs by state, gives the wall clock from first start to last end, and names the slowest run with its ratio to the median.
  Failed runs are timed too.
  `--label` takes a glob, so `--label 'screen-1/*'` gathers a screen whose runs are each named after their candidate.
  `rietx.runs.job_summary` returns the same summary in Python.
