- **A phase's peak equation reads `wavelength`** (WP-2152, #1785).
  `wavelength` is the λ in Å of the emission line the peak is drawn at, so a Kα2 image reads its own.
  A size term is then written once, as `y*wavelength/cos(theta)`, with `y` shared by patterns at several wavelengths.
  An instrument-level equation cannot read it.
  `PEAK_EQUATION_SHARED_ACROSS_WAVELENGTHS` is silent on an equation that reads `wavelength`, so it also misses a size term in degrees written beside it, as `+ x/cos(theta)`.
