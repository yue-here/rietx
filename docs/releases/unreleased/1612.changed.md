- `validate_by_lebail` handed a peak list with no usable line no longer raises numpy's `ValueError: array of sample points is empty` from the line screen (#1468).
  `PatternScreen.fwhm_at` reads zero on such a list, as `half_width_at` already did.
  The call then returns a converged validation with 0 absences for any cell, the wrong ones included, because no predicted line is testable on such a list.
  Those 0 absences are not evidence about the cell.
