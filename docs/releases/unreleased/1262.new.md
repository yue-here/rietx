- **`capabilities().solve_engines`** lists the structure-solution engines the
  build registers (#1262, #562 S2b), at the same schema number, `0.62`. The
  solver itself, `rietx.solve`, stays provisional and unexported from `rietx`.
- **A checkpoint format for a structure-solution run**, `rietx-solve-checkpoint/1`:
  an interrupted run resumes byte-identically, and a resume across a package
  version difference is refused, so a refused resume costs a restart and never a
  wrong answer. Two trees of one development version carry the same stamp, so
  a resume across their code is not refused.
