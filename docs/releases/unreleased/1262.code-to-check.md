- **Event lines and run headers say `"v": "4"`** (#1262, #562 S2b). A structure
  solution adds the kinds `solve_start`, `solve_step` and `solve_end`, which is
  the bump from 3. `read_events` now refuses a kind older than its line's `v`
  names, and a `v` that is not a whole number. Every log 1.12.0 wrote carries a
  whole-number `v` and only the kinds its version knew, so each still reads. Code
  that compares the header's `v` against `"3"` needs the new number.
