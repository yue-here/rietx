- **Schema 0.62 adds `ExtinctionScreen.held_screen` and `.background_seeded`** (WP-1910).
  `held_screen` is the second screen below, additive and defaulting to `None`; `background_seeded` says, on that held screen, whether its all-zero declared background was seeded, and is `None` on any other screen.

- **`ExtinctionScreen.best_or_none()` can return `None` where it returned a class** (WP-1910, ruled on #1178).
  With the default `refine_cell=True`, a screen that names a class is checked by a second screen at the same cell, held, from the declared instrument (`ExtinctionScreen.held_screen`; the preset's all-zero background is seeded first, as the cell-free fit seeds it, and `background_seeded` records whether it was).
  When the two name different classes they share no space group, so `best_or_none()` returns `None`, `ExtinctionScreen.screens_disagree()` is true and the warning `EXTINCTION_SCREENS_DISAGREE` names both; both rankings are kept.
  `LAUE_CLASS_NOT_SEPARABLE` and `EXTINCTION_GROUPS_NOT_SEPARABLE`, which describe the first screen's class, are not raised then.
  Code that reads `best_or_none()` and expects a class where the screens split now gets `None`, and reads `candidates` and `held_screen.candidates` instead.
  `capabilities().indexing_thresholds_version` is `1.13`, where 1.12.0's was `1.12`: no threshold moves, a screen's answer does.
  Measured before WP-2076 the check turned six confident wrong classes into abstentions on three patterns and cost eleven right answers on the GSAS-II PbSO₄ X-ray histogram from the all-zero preset background.
  Re-measured on `main` after WP-2076, it fires on none of 150 rows of those three patterns, and withholds no PbSO₄ answer (13 of 14 scales name `P c - a`, one nothing).
  A screen that names a class costs about a third to a half more time.
