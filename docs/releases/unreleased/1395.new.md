- The GUI's Series panel has a trace along the series (WP-1317, #1395).
  It draws every pattern of the chain, failed ones included, on the experiment's own axis, with the series verdicts as glyphs, each pattern's own findings as bars and the largest step of the parameter on show as a band.
  Dragging along it, or the arrow keys, Home and End, shows each pattern's own fit in the plot below with the reader's zoom kept, and a row's History button still opens that pattern's tree.
  The trace's marks come from one table, `rietx.gui.series.TRACE_VOCABULARY`, which the GUI guide's table is held to.
