- `read_pattern` warns `PATTERN_INTENSITY_NOT_COUNTS` when a pattern has no usable σ and some intensity lies between 0 and 1 or below 0 (WP-1952, WP-2002 B5.2).
  No count takes such a value, and the Poisson fallback √max(y, 1) gives each one σ = 1, so a pattern normalised below one count was fitted unweighted, in silence.
  The message counts the points and gives their 2θ. It is a report: no weight changes.
