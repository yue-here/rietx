- **A value clicked in the GUI opens on its full stored value** (WP-2223). The Parameters panel's editor and the Interactive tab's value box draw a number rounded and edit it to its last digit, as a spreadsheet cell does: `4.1568(2)` opens as `4.15678`.
  Text left as it opened is no edit, so a click in and out, or Enter on it, records nothing. Before, Enter on an unchanged Interactive value moved it by its 13th digit and recorded an edit.
  The Parameters panel now sends its rounded digits typed in, `4.1568` for `4.15678`, as an edit, where before it dropped them as unchanged.
  The Interactive value box reads `1.5×10⁻³` and `1.5x10^-3`, as the range fields do.
