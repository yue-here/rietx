- **A magnetic fit whose reflections reach past Cr²⁺, Mn²⁺ or Mn³⁺ ⟨j₀⟩'s fitted range now raises** (#1796). Brown fitted those three rows to sinθ/λ ≤ 1.5 Å⁻¹, and each carries a negative exponent, so past it the value grows: Mn²⁺ ⟨j₀⟩ was 1.01 at s = 3 Å⁻¹ and 73 at s = 4. The first stage compile refuses, naming the phase, the atom, the row, its range and the 2θ to end the data at. `j0`, `j2` and `magnetic_form_factor` raise the same way when called past it. A fit inside the range is unchanged, bit for bit.
