- **`best_or_none()` can return `None` where 1.12.0 returned a candidate** (WP-1998, #1383).
  A `SuggestionResult` whose leading group's own ΔBIC refuses it printed "ΔBIC refuses it" and still handed that parameter to `best_or_none()`. It now abstains, as `Refinement.summary()`'s `next:` line already did. A script that frees `best.path` unconditionally must handle `None`.
  `ParameterCandidate.gain` is now the gain the candidate can reach inside the box a stage would solve it in, so a saved 1.12.0 number does not compare with it. The unbounded figure is the new `ParameterCandidate.gain_unbounded`, and `SuggestionResult.bound_limited` lists the candidates whose leverage only their bound refuses.
