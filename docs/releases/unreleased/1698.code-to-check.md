- A cell parameter the space group ties to another must now agree with it. Under
  `F m -3 m`, b and c must equal a; under `P 4/m m m` or `P 6/m m m`, b must
  equal a; on rhombohedral axes, β and γ must equal α (#1669). The parameter
  table used to build the tied value from its source and drop the stored one
  silently, at any size. It now refuses a tied length more than
  `SYMMETRY_LENGTH_RTOL` (1e-5, 10 ppm in d) from its source, naming the entry,
  both values and the symbol. A script that edits `cell.a.value` on a cubic
  phase edits `cell.b` and `cell.c` with it, or calls
  `Refinement.set_values({"phases.0.cell.a": ...})`, which moves them.
  A CIF whose tied values agree within its printed digits is read as the
  source and reports `CIF_CELL_TIE_CORRECTED`. The GSAS-II, GSAS, TOPAS,
  FullProf and recipe readers refuse a larger disagreement naming the file.
  A history an older release stored with such a cell opens as every fit of it
  read it, and says `HISTORY_CELL_TIE_CORRECTED`.
