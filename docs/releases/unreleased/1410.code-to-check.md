- **`SEQUENTIAL_MOMENT_ONSET` is always `info` now, and a new code carries its
  warnings** (WP-2003). The onset bracket used to raise at `warning` when its
  supported side stopped early, when the verdicts switched more than once, or
  under `direction="both"` when the two chains disagreed. Each of those is now
  `SEQUENTIAL_MOMENT_ONSET_UNRESOLVED`, at `warning`, on the same site, and the
  bracket row stays `info` beside it. Code that read the onset row's level to
  decide whether to quote the bracket reads the new code instead. Its message
  names the reason, and its `value` is `None`: a row the backward chain alone
  located used to carry that bracket's midpoint. `SEQUENTIAL_MOMENT_HOLD` now
  names every pattern reseeded to the moment floor, where it cut the list at
  four.
