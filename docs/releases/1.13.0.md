## Upgrading

Code written against 1.12.0 runs unaltered.

### Code to check

- `capabilities().schema_version` is `0.62`, where 1.12.0's was `0.61`.
  0.62 adds `Phase.peak_equations` and `Instrument.peak_equations` (WP-2107).
  `capabilities().expression_grammar_version` is `2`: the grammar gains `orbit_mean` and `harmonic`, which only a peak equation may call.
  A tie, a variable or a `ParametricEquation` that names either is refused at declaration.

- A plan no longer ends in a closing stage unless it asks for one
  (WP-2222). Code that reads `result.stages[-1].name == "closing"` or
  counts `len(plan.run_stages()) == len(plan.stages) + 1` now sees the
  declared stages alone. Set `plan.closing_window_tol =
  rietx.schemas.plan.CLOSING_WINDOW_TOL` to get the 1.10-1.12 behaviour.

### Numbers that move

- Every default fit (WP-2222). With no closing stage, a fit is 1.2-1.9×
  faster than in 1.12 (11-BM NAC 0.53→0.43 s, CPD cpd-1a 1.65→0.97 s, cpd-2
  3.5→2.1 s on an arm64 Mac), and its answer moves by 0.16-2.0 plain esd.
  `Refinement.run_stage` and a FitReport action applied
  in the GUI now run on the declared stages' 2 % windows instead of 1e-3.
  A project saved with a plan under 1.10-1.12 stored `closing_window_tol:
  0.001` and keeps its closing stage until that line is set to `none`.

### Files that change

- A structure or instrument written by 1.13 carries `peak_equations`, as an empty list when none is declared (WP-2107).
  1.12.0 forbids unknown keys, so it refuses a phase or instrument carrying it (`docs/contracts/schema.md`, 0.61 → 0.62).
  Not yet measured against 1.12.0 from PyPI; the cut measures it both ways.

## New

- **An equation over a reflection** (WP-2107, #1635).
  `rx.PeakEquation(target, expression, coefficients)` sets a peak's width, position or intensity from its `h`, `k`, `l`, `m`, `d`, `theta` and `two_theta`.
  The targets are `lor_fwhm`, `gauss_fwhm`, `gauss_fwhm_squared`, `shift` and `intensity_factor`, and an instrument-level equation takes `shift` only.
  Each coefficient is a table entry with an exact derivative.
  An equation that differs between the images of one Laue orbit is refused, naming the reflection; `orbit_mean(...)` averages over the orbit and `harmonic(l, n)` reads a symmetric harmonic of the direction.
  Three diagnostics are new: `PEAK_WIDTH_NOT_POSITIVE`, `QPA_INTENSITY_FACTOR` and, in a joint fit across wavelengths, `PEAK_EQUATION_SHARED_ACROSS_WAVELENGTHS`.
  The guide is `guides/peak_equation.md`.
