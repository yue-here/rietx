# Diagnostics: corrections

These codes come from a physical correction the model declares, or one the fit's residual asks for: absorption, surface roughness, anomalous dispersion, wavelength harmonics, texture, Stephens strain and declared peaks.
Each section gives the code's name, what it means and why it fires, its level, and the source files that raise it.
The [diagnostic codes](diagnostics.md) page lists every code in one table.
