# Instrument parameter map

This page lists the parameters of the instrument, the time-of-flight source and the background, grouped by what each does to the pattern.
[Parameter map](parameters.md) lists the phases' parameters and the named variables, and explains how the names are written.

Each row gives the parameter's unit, its default and a typical range to check a refined value against.
A parameter with no default takes its value from the instrument you load.
