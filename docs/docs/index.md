# The rietx manual

rietx is a Python package for Rietveld, Le Bail and Pawley refinement of powder diffraction data.

::::{grid} 1 1 3 3
:gutter: 3

:::{grid-item-card} New to rietx
:link: start/index
:link-type: doc

You know Rietveld refinement and want your first fit in rietx. Start with a Le Bail fit of a standard, then a full refinement.
:::

:::{grid-item-card} Coming from another code
:link: switching/index
:link-type: doc

You use TOPAS, GSAS-II or FullProf. See what rietx does the same, what it does differently, and how it was validated.
:::

:::{grid-item-card} Supervising an agent
:link: guides/index
:link-type: doc

An agent runs the fits and you check them. See what to read in a report and when to stop a run.
:::
